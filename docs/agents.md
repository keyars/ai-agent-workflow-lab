# Agent Catalogue

| # | Agent | Production role |
|---|---|---|
| 01 | MCP Security Gateway | authorize MCP tool use |
| 02 | Agent Action Firewall | deterministic action policy |
| 03 | Agent Sandbox Runner | isolate untrusted execution |
| 04 | Browser Workflow Agent | browser task execution |
| 05 | Workflow Recorder | capture reusable actions |
| 06 | Workflow Generator | intent to executable workflow |
| 07 | Workflow Validator | safety and operability linting |
| 08 | Agent Observability | trace runs, tools and cost |
| 09 | Agent Evaluation Lab | benchmark agent quality |
| 10 | Agent Replay Debugger | replay recorded runs |
| 11 | Agent Cost Optimizer | optimize model/tool spend |
| 12 | Agent Memory Optimizer | classify and compress memory |
| 13 | Prompt Injection Firewall | detect hostile instructions |
| 14 | Tool Discovery Engine | select relevant least-privilege tools |
| 15 | MCP Server Generator | schema to MCP tool surface |
| 16 | REST-to-MCP Adapter | expose REST APIs as tools |
| 17 | Agent Approval Center | human approval for risky actions |
| 18 | Long-Running Task Engine | durable pause/resume/cancel |
| 19 | Agent Failure Recovery | retry and alternative paths |
| 20 | Agent Security Scanner | scan agent systems for gaps |

Every module is intended to become independently executable, testable and composable through the shared runtime.
